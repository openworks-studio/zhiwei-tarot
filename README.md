# 知微 · 塔罗时笺

一个可以直接部署到 GitHub Pages 的纯静态塔罗页面，无需数据库或后端。

## 功能

- **今日三时**：抽取三张牌，对应“缘起 / 当下 / 走向”，显示逐张解读与综合批语。
- **一念决事**：针对一件小事抽一张牌，显示四字批语、牌意与行动建议。
- **分享结果**：浏览器本地生成 1080 × 1440 PNG 分享图，支持下载或手机长按保存。
- **隐私**：问题、抽牌和图片均在浏览器本地处理，不上传任何内容。
- **自包含**：无第三方字体、脚本、图片或 API 依赖，可离线打开。

## 本地预览

直接双击 `index.html` 即可使用。也可以在目录中运行：

```powershell
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `zhiwei-tarot`。
2. 把本目录下的全部文件上传到仓库根目录并提交。
3. 打开仓库的 **Settings > Pages**。
4. 在 **Build and deployment** 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/ (root)`，点击 **Save**。
6. 等待约 1-3 分钟，页面地址通常为：

```text
https://你的GitHub用户名.github.io/zhiwei-tarot/
```

## 小红书使用说明

小红书笔记正文中的普通外链通常不能直接点击，且不同账号的跳转权限可能不同。更稳妥的方式是使用平台允许的店铺商品、私信自动回复或个人主页入口承接访问，并在售卖前自行确认最新平台规则。

不要把 GitHub Pages 当作付费访问控制：公开仓库和公开 Pages 链接拿到后可以继续转发。如果需要“一人一单一码、过期失效”之类的防转发能力，需要额外的支付/鉴权服务，纯静态 GitHub Pages 无法做到。
